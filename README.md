This is a calculation to estimate the payback period for adding EWI to a solid brick wall.
Numbers largely taken from "Housebuilder's Bible" by Mark Brinkley, 14th Edition.

You need python or jupyter to run it. Email me if you need help setting these up, 
but note that I don't know much about doing this on Windows or Mac.

It could do with a tidy up, but I couldn't find anything equivalent ready-made.

You need to read [Part L](https://www.gov.uk/government/publications/conservation-of-fuel-and-power-approved-document-l) to understand the background.
I have no qualifications in this area: I just wanted to understand my options as a client.

I've loaded up this notebook in mybinder.org. You can access it as a runnable (and editable) notebook
at [![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/stevehemingway/Part-L/HEAD)
